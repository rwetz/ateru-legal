# Ateru legal

Public home for the documents [Ateru](https://github.com/rwetz/ateru) has to publish.
The app itself is a private repository; this one exists so the App Store, and anyone
who asks, has a stable URL.

| Document | URL |
|---|---|
| Privacy Policy | https://rwetz.github.io/ateru-legal/privacy |
| Open-source notices | https://rwetz.github.io/ateru-legal/notices |

**`NOTICES.md` is generated** by `app/tool/build-licences.mjs` in the app repository
and copied here, so do not edit it by hand. CI in that repository fails if it drifts
from what the dependency tree actually contains.

There is no terms-of-service document, and that is deliberate: Apple's standard
[Licensed Application End User License Agreement](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)
applies to Ateru, and a free app with no accounts and no purchases has nothing to add
to it.
